# Repository Instructions

- Keep this repository subject-neutral and learner-adaptive.
- Do not add personal learning records, course-platform IDs, local absolute paths, paid course media, login state, or credentials.
- Validate `codex-skill/adaptive-course-teacher` with the Codex skill validator after changing the skill.
- Keep HTML samples self-contained through local dependencies and verify their relative references.
- Write new or substantially changed non-vendor code in TypeScript. JavaScript is allowed only as generated or bundled browser output, vendored dependencies, or unavoidable tool configuration. Keep the editable TypeScript source, compile locally, and do not hand-edit generated JavaScript.
- Separate changes into logical commits: skill workflow, project template, HTML examples, and documentation.
- After meaningful updates, commit each logical concern separately and push it to `origin/main`.
- Do not amend, rewrite, squash, force-push, or delete remote history unless the user explicitly requests it.
