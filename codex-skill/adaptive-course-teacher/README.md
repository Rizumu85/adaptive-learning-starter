# Adaptive Course Teacher

An iterative learning skill for courses, books, and other study materials. Begin with a short reading or viewing map, reconstruct confusing reasoning after the learner responds, and select durable notes or media for specific needs.

A broad learning request starts one small unit, not an entire generated curriculum. Explicit batch requests remain supported within their stated scope. Generated artifacts are not evidence of learner mastery.

## Usage

Read `SKILL.md` for entry points. Books use `references/book-learning.md`; software learning additionally uses `references/software-learning.md`. Ask to study one unit, or explicitly specify the scope of a batch deliverable. Visual examples and themes are optional.

Install this directory as a skill in your agent's supported skill location. Project setup instructions and templates are in the starter repository's root README and `project-template/`. No credentials are bundled.

## Boundaries and Data

This is a collaborative learning workflow, not an automatic whole-source publishing pipeline. Source materials remain local unless redistribution is authorized. Never record generated content as learner mastery.
